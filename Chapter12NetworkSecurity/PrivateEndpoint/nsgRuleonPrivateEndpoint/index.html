Azure Storage Access via Private Endpoint

This page is served by Nginx on an Azure Linux VM at port 30080. The VM downloads index.html from Azure Blob Storage using the Storage Account's Private Endpoint.

🌍 VM Web Access — Public path

http://<VM-PUBLIC-IP>:30080 A student connects to Nginx on the VM. The VM's public web access does not mean Storage must be public.

🔒 Storage Access — Private path

https://<account>.blob.core.windows.net The Storage hostname resolves to the Private Endpoint IP. The VM connects over HTTPS port 443.

🛡️ Security benefits

  • Private network path to Blob Storage.
  • Storage public network access can be disabled.
  • Managed identity avoids storing account keys.
  • RBAC controls which blobs the VM can read.

2. How it works

  1. The VM has a managed identity assigned to it.
  2. The identity has the Storage Blob Data Reader role.
  3. The Storage Account has a Blob Private Endpoint with a private IP.
  4. DNS resolves the Blob hostname to the private IP.
  5. The setup script downloads index.html from the container.
  6. Nginx serves the downloaded file on port 30080.

3. Verify on the VM

Check hostname resolution:

getent hosts <account>.blob.core.windows.net

Check Nginx:

sudo systemctl status nginx

Test the website locally:

curl http://127.0.0.1:30080/

Test the Storage TLS connection:

curl -v https://<account>.blob.core.windows.net/ -o /dev/null

4. Lab checklist

  • Private Endpoint is approved and connected.
  • VM can reach the private IP on TCP 443.
  • Blob hostname resolves to the intended private IP.
  • Managed identity has the correct Blob data role.
  • index.html downloads successfully.
  • NSG permits inbound TCP 30080 if browser access is needed.
Teaching note: The sample VM script downloads the HTML file and Nginx serves that local copy. The browser does not fetch the HTML directly from Storage. Rerun the download step to refresh the page after the blob changes. For production, use Azure Private DNS for the Blob Private Endpoint instead of a hardcoded /etc/hosts entry.
