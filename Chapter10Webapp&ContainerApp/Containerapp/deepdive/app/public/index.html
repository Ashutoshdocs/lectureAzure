1 · Who answered this request?

Container Apps injects the app, revision and replica name into every container. A Web App has no "revision" concept.

2 · Event-driven autoscale (KEDA)

Fire concurrent requests that each hold for a few seconds. The HTTP scale rule adds replicas, then removes them — down to zero when idle.

5 · What Container Apps can do that App Service (Web App) cannot

Both run containers. The difference is the platform model: Web Apps are "always-on web servers on a plan"; Container Apps are "serverless Kubernetes for microservices".
