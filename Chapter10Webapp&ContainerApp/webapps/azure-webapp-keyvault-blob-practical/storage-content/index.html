Key Vault + Managed Identity

Hello from a private Azure Blob!

This HTML file is stored in a private Azure Blob Storage container.

The Python Web App uses its system-assigned managed identity to retrieve the Storage Account connection string from Azure Key Vault. It then uses that connection string to download this HTML file.

What this practical demonstrates

  1. The Storage connection string is stored as a Key Vault secret.
  2. The Web App authenticates to Key Vault using Managed Identity.
  3. Key Vault RBAC grants the identity permission to read secrets.
  4. The app uses the retrieved connection string to read the private blob.

Security point: The connection string is not hardcoded in source code or saved in the Web App application settings.
