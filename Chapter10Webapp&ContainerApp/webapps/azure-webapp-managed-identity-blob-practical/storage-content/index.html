Azure Managed Identity

Hello from a file stored in Azure Blob Storage!

This HTML file lives in a private Blob Storage container.

The Azure App Service retrieves this page at request time by using its system-assigned managed identity.

What this practical demonstrates

  1. The HTML file is uploaded to a private blob container.
  2. The Web App has a system-assigned managed identity.
  3. The identity is granted the Storage Blob Data Reader role.
  4. The Python application downloads the blob using Microsoft Entra ID.

Security point: no storage account key, SAS token, or connection string is embedded in the application.
