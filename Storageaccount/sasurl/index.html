How It Works

1

Browser sends a request to the Application.

2

Application reads the Azure Storage Connection String.

3

Application generates a temporary Shared Access Signature (SAS).

4

SAS URL is returned securely to the browser.

5

The browser loads the private image directly from Azure Blob Storage.
